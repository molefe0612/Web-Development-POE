## Project Overview
TS-Lets Confectionary began as a local home-based baking operation before expanding into a registered bakery situated along the R71 road near Paledi Mall in Mankweng, Limpopo.
 Officially established as a formal business in May 2015 by local entrepreneur Tshepo Letsoalo, the cake shop has built an exceptional local reputation for providing custom celebration cake
 that are highly regarded as beautiful and tasty.

* **Mission:** To bake joy into the heart of our community by providing freshly prepared,
 high-quality hand-crafted custom cakes using premium ingredients at affordable prices.
* **Vision:** To become the premier custom bakery and confectionery destination
 across the Mankweng and greater Polokwane region, celebrated for innovative designs and shared memories.
* **Target Market:** 
  * The Celebration Planners (Custom Cake Market)
  * The On-The-Go Snackers (Takeaway Market)

## Website Goals and Objectives
### Core Goals:
* Establish a professional online presence.
* Generate recurring order inquiries.
* Attract and systematically manage local customers.

### Core Objectives:
* Streamline customer custom ordering pathways.
* Reduce dependency on external social media channels.
* Enhance consumer brand trust.

### Key Performance Indicators (KPIs):
* Total website visits (monthly unique local users).
* Map navigation link clicks targeting the physical location along the R71.
* User bounce rate percentage tracking single-page sessions.
* Comprehensive count of orders finalized online versus physically in-store.

## Key Features and Functionality
* **Core Front-End Tech Stack:** Built using pure HTML, styled with CSS layout properties, and interactive elements handled via JavaScript.
* **UI/UX Design Approach:** A distinct mobile-first view structure layout built specifically for smartphone shoppers, integrated with a clear sticky top navigation menu for quick contact reference access.
* **Color System:** Pastel pink primary accents (frosting/sweetness), warm chocolate brown elements (text/borders), and a clean creamy off-white body canvas layout background.
* **Typography Hierarchy:** Playfair Display for display-level elegant headings combined with Arial or Roboto for highly legible main body blocks.

## Part 2 Details
This phase is about a professional, cohesive presentation layer using **CSS**  over the baseline semantic structures. 

### Key Technical Executions:
* **Global Box Normalization:** Utilizes full universal border-box resets (`* {box-sizing: border-box}`) to eliminate unwanted margin/padding overflow issues.
* **Cohesive Bakery Theme:** Establishes visual hierarchy using a warm palette consisting of a dark chocolate header/text theme (`#4A2E2B`), contrasting bright pink structural border lines (`#E05A7B`), and deep pastel canvas base filters (`#EBE0D5`).
* **Responsive Architecture:** Implements a fluid **CSS Grid Layout** with multi-device breakpoints (`@media`) that gracefully scale from large desktop windows down into a single-column layout optimized for smartphone shoppers.
* **Interactive Enhancements:** Features high-performance interactive states including native hover scale transforms (`scale(1.06)`) on product cake cards and dynamic accessibility outline rings (`#FF69B4`) for navigation links during keyboard focus.
