## Project Overview
TS-Lets Confectionary began as a local home-based baking operation before expanding into a registered bakery situated along the R71 road near Paledi Mall in Mankweng, Limpopo. Officially established as a formal business in May 2015 by local entrepreneur Tshepo Letsoalo, the cake shop has built an exceptional local reputation for providing custom celebration cakes that are highly regarded as beautiful and tasty.

- **Mission:** To bake joy into the heart of our community by providing freshly prepared, high-quality handcrafted custom cakes using premium ingredients at affordable prices.
- **Vision:** To become the premier custom bakery and confectionery destination across Mankweng and the greater Polokwane region, celebrated for innovative designs and shared memories.
- **Target Market:** 
  - **The Celebration Planners:** Custom Cake Market
  - **The On-The-Go Snackers:** Takeaway Market

## Part 2 Details
This phase is about a professional, cohesive presentation layer using **CSS** over the baseline semantic structures. 

### HTML Structure Refactorings (Part 1 to Part 2)
I changed a few tags like `<table>`, `<tr>`, and `<td>` to `<div>` and `<span>`. These changes make the code more organized and well-aligned. Initially, I used the table tag to align pictures easily, but they were rigid, difficult to modify, and made the structure too complicated to edit—leading to errors. Using the `<div>` tag is far easier to understand, keeps the layout clean, and simplifies maintenance.

### Key Technical Executions
- **Global Box Normalization:** Utilizes full universal border-box resets (`* { box-sizing: border-box; }`) to eliminate unwanted margin/padding overflow issues.
- **Cohesive Bakery Theme:** Establishes visual hierarchy using a warm palette consisting of a dark chocolate header/text theme (`#4A2E2B`), contrasting bright pink structural border lines (`#E05A7B`), and deep pastel canvas base filters (`#EBE0D5`).
- **Responsive Architecture:** Implements a fluid **CSS Grid Layout** with multi-device breakpoints (`@media`) that gracefully scale from large desktop windows down into a single-column layout optimized for smartphone shoppers.
- **Interactive Enhancements:** Features high-performance interactive states including native hover scale transforms (`scale(1.06)`) on product cake cards and dynamic accessibility outline rings (`#FF69B4`) for navigation links during keyboard focus.

## Part 3 Details: Search Engine Optimization (SEO) & JavaScript Functionality

### 1. Define SEO and explain its purpose in web development
Search Engine Optimization (SEO) is the practice of optimizing a website's structure, content, and code to improve its visibility on search engine results pages (SERPs). In web development, its primary purpose is to drive organic local traffic, helping nearby customers searching for custom celebration cakes or takeaways easily discover the bakery online.

### 2. Explain how SEO practices can improve user experience (UX) and website performance
SEO heavily overlaps with good UX by prioritizing fast page-loading speeds, mobile responsiveness, and clean semantic HTML structures. When a site is optimized for search engines, visitors also benefit from an intuitive navigation layout, readable typography, and quick access to essential information like location and menus.

### 3. Discuss the benefits of implementing SEO on a website
Implementing SEO establishes long-term brand credibility and trust for local businesses like TS-Lets Confectionary. By ranking higher for regional search terms (e.g., custom cakes in Mankweng), it reduces dependency on external social media channels and systematically generates direct customer order inquiries.

### 4. Explain and demonstrate specific SEO techniques using HTML, CSS, and JavaScript
Effective technical SEO involves using semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<h1>`) to give search engines a clear structural hierarchy. In CSS, optimizing asset delivery ensures fast rendering, while JavaScript can be used responsibly for dynamic content rendering without blocking initial page indexing.

### 5. Explain the purpose of HTML meta elements and relevant examples
HTML meta elements provide structured metadata about a web page to search engines and browsers within the `<head>` section. They control how pages are indexed and previewed on SERPs.

**Example Implementation:**
```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="TS-Lets Confectionary offers freshly prepared handcrafted custom celebration cakes and takeaways along the R71 in Mankweng, Polokwane.">
  <title>TS-Lets Confectionary | Custom Cakes & Bakery</title>
</head>
